# Audit antislop: 005-2026-10-21
Target: `index.vue` (Mobile Bottom Sheet & Filter Wilayah MVT), `MapCanvas.vue` (Dynamic MVT Style & Filter Reactivity), `LeftPanel.vue`

## Status Evaluasi
Audit implementasi Tab Geoportal pada Mobile Device dan Reaktivitas Filter Wilayah Layer Vektor MVT sesuai preferensi antislop Mode 2 (After):

### Temuan & Review Kepatuhan:
1. **[LULUS] Ketersediaan Tab Geoportal pada Perangkat Mobile (R-30, antislop-layoutmobile)**:
   - Menambahkan tab **Geoportal** (`i-lucide-globe-2`) ke dalam quick tab switcher `MapMobileBottomSheet` mobile drawer (kini terdiri dari 4 tab: `Layer`, `Geoportal`, `Wilayah`, `Lokasi`).
   - Menyediakan header title (`Katalog Geoportal`), subtitle status resmi JIGN, dan ikon representatif saat tab Geoportal aktif.
   - Mengintegrasikan `GeoportalLayerSection` secara persisten di dalam mobile drawer melalui instance `LeftPanel` tanpa remounting, sehingga state pencarian, kategori, dan ekspansi accordion tetap terjaga mulus saat beralih tab.

2. **[LULUS] Ergonomi Mobile & Tap Target Standard (antislop-layoutmobile, R-18)**:
   - Setiap tab button pada navigation bar sheet memenuhi target sentuh minimum (`min-h-[40px]`, `touch-manipulation`, dan padding proporsional).
   - Mengadopsi tata letak adaptif (`flex-col sm:flex-row`) dengan penataan label teks yang terpotong aman (`truncate max-w-full text-[11px] sm:text-xs`) sehingga tidak menyebabkan teks terpotong canggung atau memicu horizontal scrollbar pada layar ponsel sempit (360px - 390px).
   - Tapping pada tab button saat bottom sheet berada pada posisi snap `min` secara otomatis mengangkat sheet ke snap level `peek` untuk memudahkan eksplorasi.

3. **[LULUS] Reaktivitas Filter Wilayah pada Layer Vektor MVT (R-01, R-14)**:
   - Memperbaiki bug pada OpenLayers `VectorTileLayer` di `MapCanvas.vue` di mana style function sebelumnya menutup (*closure*) nilai awal `layer.filterKecamatan` dan tidak memperbarui render cache saat filter berganti.
   - Mengimplementasikan `createMvtStyleFn` dinamis yang membaca langsung properti layer `olLayer.get("filterKecamatan")` dan `olLayer.get("filterStatus")`.
   - Mengatur ulang style layer dengan `olLayer.setStyle(createMvtStyleFn(olLayer, isSegmen))` dan memanggil `olLayer.changed()` setiap kali nilai filter kecamatan berubah, memaksa OpenLayers membuang cache render lama dan me-render ulang fitur secara instan.
   - Menormalisasi pencocokan nama kecamatan (menghilangkan prefix `"kecamatan"` / `"kec."`, *trimming*, dan *case-insensitive comparison*) agar cocok dengan variasi nilai data pada tabel PostGIS `infrastruktur_segmen` dan `jalan_porosdesa`.

4. **[LULUS] Pencegahan Identifikasi Fitur Terfilter (antislop-human, R-22)**:
   - Pada penanganan klik peta `forEachFeatureAtPixel`, menambahkan validasi aktif terhadap hasil evaluasi `styleFn(feature, resolution)`. Fitur jalan atau segmen yang disembunyikan oleh filter wilayah tidak lagi dapat diklik atau memicu popup informasi yang tidak relevan.

5. **[LULUS] Alur UX Pemilihan Wilayah di Mobile Drawer (R-30, R-34)**:
   - Memisahkan penanganan pemilihan kecamatan (`handleSelectKecamatan`) dari pencarian global (`handleSelectLocation`).
   - Saat pengguna mengetuk kecamatan pada Tab Wilayah di perangkat mobile, kamera peta melakukan animasi pergerakan halus (`flyTo`) ke koordinat kecamatan dengan zoom 13.5, sementara drawer tetap berada di Tab Wilayah untuk menampilkan status filter aktif (badge biru) dan tombol "Reset", tanpa melompat paksa ke tab Lokasi/Inspector.

### Ringkasan:
Tidak ditemukan pelanggaran tingkat **HIGH**, **MEDIUM**, maupun **LOW**. Seluruh fungsionalitas Tab Geoportal di mode mobile dan Filter Wilayah pada layer MVT telah lulus uji dan berfungsi optimal.
