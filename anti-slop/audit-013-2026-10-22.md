# Audit antislop: 013-2026-10-22
Target: `MapMobileBottomSheet.vue`, `maps/index.vue`

## Status Evaluasi
Evaluasi kepatuhan antislop Mode 2 (After) untuk penyesuaian header, mekanisme minimize, visibilitas default, dan penghapusan tombol toggle layer di mode mobile:

### Temuan & Review Kepatuhan:
1. **[LULUS] Penghapusan Fitur Share pada Header Bottom Sheet (antislop-ui, R-01, R-24)**:
   - Slot `#header-actions` pada `MapMobileBottomSheet` di `maps/index.vue` telah dihapus.
   - Header bottom sheet kini lebih ringkas dan fokus langsung pada judul, subtitle status, dan kontrol snap level. Fitur bagikan peta tetap dapat diakses melalui toolbar navigasi peta (`MapControls.vue`) dan menu detail titik lokasi (`BottomLocationBar.vue`).

2. **[LULUS] Aksi Tutup Disederhanakan Khusus untuk Minimize (antislop-layoutmobile, antislop-ui, R-03, R-35)**:
   - Tombol tutup (`i-lucide-x`) pada header kini berfungsi secara konsisten untuk **mengecilkan/meminimize** panel ke snap level `min` alih-alih menutup dan menghilangkan panel dari layar.
   - Fungsi `close()` internal diubah dari `emit('update:open', false)` menjadi `snapTo('min')`.
   - Gerakan usap ke bawah berkecepatan tinggi (*flick down*) dari level `min` maupun tarikan ke bawah melampaui batas toleransi (`offset > min + 55`) kini membal secara elastis (*rubber-band*) dan mempertahankan posisi di level `min`, menjaga bottom sheet tetap ada di bagian bawah layar.
   - Saat berada di posisi `min`, tombol tutup disembunyikan dan hanya menampilkan tombol buka (`i-lucide-chevron-up`) dengan target sentuh ergonomis 44x44px.

3. **[LULUS] Bottom Sheet Default Terbuka pada Mode Mobile Device (antislop-layoutmobile, R-03, R-35)**:
   - `mobileDrawerOpen` kini secara default bernilai `true` dan `mobileSheetSnap` bernilai `'peek'`.
   - Pengguna pada layar smartphone langsung disajikan daftar lapisan peta dan kendali peta dasar tanpa harus mencari tombol pembuka.

4. **[LULUS] Eliminasi Tombol Toggle Layer pada Mode Mobile (antislop-layoutmobile, antislop-ui, R-03, R-10)**:
   - Tombol mengambang (*floating button*) "Lapisan Peta" di kiri-bawah kini diberi kelas `hidden md:block`.
   - Di perangkat smartphone, tombol ini dihilangkan sepenuhnya sehingga tidak menutupi area peta atau bertabrakan dengan bottom sheet.
   - Di perangkat desktop, tombol tetap hadir dan berfungsi membuka `LeftPanel` seperti biasa.

### Ringkasan:
Tidak ditemukan pelanggaran tingkat **HIGH**, **MEDIUM**, maupun **LOW**. Seluruh 3 permintaan pengguna telah diimplementasikan dengan kepatuhan penuh terhadap standar antislop.
