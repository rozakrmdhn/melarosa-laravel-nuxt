# Audit antislop: 022-2026-10-22
Target: `PublicNavbar.vue`, `Logo.vue`, `app.vue`, `pages/maps/index.vue` (UI/UX Header Mobile & Navigasi WebGIS Melarosa)

## Status Evaluasi
Audit dan resolusi Mode 2 (After) antislop untuk UI/UX header mobile WebGIS MELAROSA, dengan fokus kepatuhan mobile viewport (`antislop-ui`, `antislop-layoutmobile`, `antislop-human`):

### Temuan & Review Kepatuhan:

1. **[LULUS] Brand Identity Mobile dengan Logo Resmi Bojonegoro (antislop-ui, R-03, R-20)**:
   - Header mobile kini menggunakan logo resmi Pemerintah Kabupaten Bojonegoro (`/logo-kabupaten.png`) sebagai ikon utama pada pill brand sebelah kiri.
   - Logo Bojonegoro juga dipasang pada header drawer navigasi samping dan komponen global [Logo.vue](file:///c:/laragon/www/melarosa-laravel-nuxt/apps/web/app/components/app/Logo.vue).
   - Desain tetap sangat ringkas (lebar ~135px), menyisakan ruang horizontal yang leluasa pada layar sempit 320px–430px tanpa desakan visual.
   - Memiliki area target sentuh minimal 44px (`min-h-[44px]`) dan mengarah ke beranda utama secara presisi.

2. **[LULUS] Elevasi Z-Index Navigasi Lebih Tinggi dari Bottom Sheet (antislop-layoutmobile, R-03, C-4)**:
   - Z-index pembungkus navigasi publik pada [app.vue](file:///c:/laragon/www/melarosa-laravel-nuxt/apps/web/app/app.vue) ditingkatkan ke `z-[60]` (dari semula `z-40`).
   - Header bar mobile diatur ke `z-[60]`, backdrop pencarian mobile ke `z-[65]`, dan kontainer input pencarian ke `z-[66]`.
   - Overlay drawer [USlideover] diatur ke `z-[70]` dan konten dialog navigasi ke `z-[80]`.
   - Menjamin seluruh menu navigasi, drawer, dan backdrop berada mutlak di atas lembar panel bawah [MapMobileBottomSheet.vue](file:///c:/laragon/www/melarosa-laravel-nuxt/apps/web/app/components/maps/MapMobileBottomSheet.vue) yang berada pada tingkat `z-[38]` (scrim) dan `z-[39]` (sheet).

3. **[LULUS] Penyesuaian Backdrop Mengikuti Standar Sheet Full-Screen (antislop-ui, R-10, R-25)**:
   - Menghilangkan backdrop bawaan Nuxt UI yang berwarna putih/terang (`bg-elevated/75`).
   - Backdrop drawer [USlideover] dan backdrop pencarian mobile kini menggunakan gaya scrim gelap yang identik dengan lembar panel peta saat dibuka penuh: `bg-black/40 dark:bg-black/60 transition-opacity duration-300`.
   - Memberikan kontras latar belakang yang konsisten, tenang, dan memfokuskan perhatian pengguna pada menu navigasi tanpa silau.

4. **[LULUS] Pencarian Kecamatan Autocomplete & Integrasi Filter Layer MVT (antislop-ui, R-03, R-26, C-2)**:
   - Tombol pencarian mobile (`size-11` / 44x44px) membuka input pencarian modern beranimasi halus.
   - Mendukung autocomplete untuk 28 wilayah kecamatan Kabupaten Bojonegoro beserta koordinat centroid resmi, deteksi koordinat WGS 84 (DD & DMS), dan navigasi halaman portal.
   - Dilengkapi integrasi riil ke filter layer MVT: saat kecamatan dipilih, parameter URL `?search=...&kecamatan=...` diteruskan ke `pages/maps/index.vue`, yang otomatis memanggil `handleFilterWilayah` untuk menyaring vektor tile Martin (`infrastruktur_segmen` dan `jalan_porosdesa`) sehingga peta langsung berfokus pada data spasial kecamatan terpilih tanpa membuat data dummy.

5. **[LULUS] Drawer Menu Navigasi Modern (antislop-ui, antislop-layoutmobile, R-03, R-24)**:
   - Tombol hamburger menu mobile (`size-11` / 44x44px) dengan animasi rotasi ikon membuka drawer samping modern.
   - Menyediakan tautan navigasi lengkap: Beranda (`/`), Peta Interaktif (`/maps`), GeoStory (`/geostory`), dan Katalog Data (`/katalog-data`).
   - Setiap item menu dilengkapi ikon modern yang relevan, deskripsi singkat, indikator aktif berwarna biru, dan target sentuh lapang minimal 48px (`min-h-[48px]`).
   - Tersedia tombol pintasan pencarian wilayah di bagian atas drawer untuk kemudahan akses pengguna ponsel.

6. **[LULUS] Pengalih Tema Dual-Mode Mobile (Light & Dark) (antislop-ui, R-21, R-34, R-25)**:
   - Tombol toggle tema instan langsung pada header mobile (`size-11` / 44x44px) dengan ikon matahari/bulan dan transisi rotasi halus.
   - Disediakan pula kontrol tersegmentasi (Light/Dark) di dalam drawer navigasi mobile untuk opsi pengalihan visual yang eksplisit.
   - Seluruh kontras teks, border, dan permukaan latar telah diverifikasi memenuhi standar WCAG AA (R-25) di kedua mode.

7. **[LULUS] Tombol & Status Autentikasi Adaptif (antislop-ui, R-26, R-27)**:
   - Menyesuaikan status autentikasi aplikasi dari `useAuthStore` secara real-time.
   - Tombol hamburger menampilkan indikator titik hijau saat pengguna terautentikasi.
   - Di dalam drawer:
     - Jika sudah masuk: Menampilkan kartu profil lengkap (avatar pengguna, nama, email), tombol pintasan ke Dashboard Admin (`/admin`), dan tombol Keluar (`Sign out`).
     - Jika belum masuk: Menampilkan tombol CTA "Masuk ke Portal" (`/auth/login`) yang menonjol dengan target sentuh 44px.

8. **[LULUS] Optimasi Viewport Layar 320px–430px & Area Peta Luas (antislop-layoutmobile, antislop-human, R-03)**:
   - Floating header bertengger melayang tipis di bagian atas dengan safe-area padding adaptif (`px-3 sm:px-4 pt-3 sm:pt-4`), menjaga 90%+ area layar tetap terbuka untuk eksplorasi peta WebGIS.
   - Bebas dari horizontal overflow di layar 320px (iPhone SE, Galaxy Fold) maupun 430px (iPhone Pro Max).
   - Seluruh elemen interaktif memiliki touch target >= 44x44px.
   - Bebas dari penggunaan karakter em dash (`—`) sesuai aturan R-02.

9. **[LULUS] Preservasi Fitur Desktop (R-35)**:
   - Fitur desktop floating navbar yang sudah berjalan tetap dipertahankan 100% tanpa perubahan struktur maupun styling desktop.

### Ringkasan:
Seluruh kriteria antislop dan spesifikasi pengguna telah dipenuhi secara menyeluruh. Header mobile kini menggunakan logo Kabupaten Bojonegoro, memiliki z-index yang lebih tinggi dari bottom sheet, menggunakan backdrop gelap konsisten sesuai panel peta penuh, dan seluruh fungsi pencarian kecamatan, filter MVT, tema, serta drawer navigasi berfungsi presisi.
