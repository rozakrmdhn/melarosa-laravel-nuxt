## Daftar Temuan Bernomor

1. **[HIGH | R-25] Kontras Teks Abu-Abu Muda dan Warna KPI di Mode Terang Gagal WCAG AA**
   - Lokasi: `apps/web/app/pages/admin/layers/index.vue` (baris 1635, 1721, 1905, 2081, 2097, 2324).
   - Bukti terukur (`contrast-check.py`): `#9CA3AF` (`text-gray-400`) di atas `#FFFFFF` menghasilkan rasio **2.54:1** (di bawah 4.5:1), `#059669` (`text-emerald-600`) di atas `#ECFDF5` (kotak KPI `Baru Masuk`) menghasilkan **3.58:1**, dan `#0284C7` di atas `#EFF6FF` menghasilkan **3.76:1** untuk teks kecil `text-[10px]`.
   - Alasan: Label sekunder seperti timestamp sync, teks `"Tidak"`, keterangan progres sync, dan label kecil kartu ringkasan sulit dibaca pada layar terang.

2. **[HIGH | R-25] Kontras Label Modal Sinkronisasi Saat Loading/Result di Mode Gelap**
   - Lokasi: `apps/web/app/pages/admin/layers/index.vue` (baris 2093, 2104, 2320, 2331, 2362).
   - Bukti terukur (`contrast-check.py`): `#6B7280` (`text-gray-500` tanpa varian `dark:text-gray-300`/`dark:text-gray-400`) di atas latar modal gelap `#0B0F19` hanya mencapai **3.96:1** (di bawah standar normal text **4.5:1**).
   - Alasan: Label KPI `"Total Ditemukan"`, `"Diproses"`, `"Durasi"`, dan catatan jadwal `02:15 WIB` terlalu redup saat tema gelap aktif.

3. **[HIGH | R-03, R-39] Ukuran Target Sentuh (Tap Target) Terlalu Kecil pada Checklist & Preset Sync Martin serta Reorder Baris**
   - Lokasi: `apps/web/app/pages/admin/layers/index.vue` (baris 1588-1606 tombol naik/turun order, baris 2236-2263 tombol preset `Utama`/`Belum Sinkron`/`Semua`/`Kosongkan`, dan baris 2274 checkbox `<input type="checkbox">`).
   - Alasan: Tombol `chevron-up`/`chevron-down` (`size-3.5`) dan tombol preset `px-2 py-1 text-[11px]` (~24px tinggi) berada jauh di bawah batas aman tap target mobile 44px, serta `<input type="checkbox">` standar tidak menggunakan target ketuk yang lapang di layar sentuh.

4. **[HIGH | R-03] Tombol "Riwayat Sync" Disembunyikan di Mobile & Tabel Riwayat Hanya Menggulir Horizontal**
   - Lokasi: `apps/web/app/pages/admin/layers/index.vue` (baris 1036 `hidden sm:inline-flex`, baris 2441 tabel riwayat 6 kolom dengan `overflow-x-auto`).
   - Alasan: Pengguna mobile `< 640px` kehilangan akses langsung ke tombol "Riwayat Sync" di header (harus masuk modal Sync dulu), dan tabel 6 kolom di dalam modal memaksa scroll horizontal alih-alih menyusun kartu ringkas per baris di viewport sempit.

5. **[HIGH | R-32, R-39] Tombol Aksi Urutan Tabel (Up/Down) Tidak Memiliki `aria-label` dan Fokus Keyboard Eksplisit**
   - Lokasi: `apps/web/app/pages/admin/layers/index.vue` (baris 1587-1607).
   - Alasan: Kedua `<button>` pengubah z-index hanya mengandalkan atribut `title` (yang tidak selalu dibacakan pembaca layar atau muncul saat fokus keyboard) dan tidak memiliki kelas `focus-visible:ring-2`.

6. **[MEDIUM | R-09, R-14] Kartu Status Kembar & Empat Kartu KPI Berpola Seragam dengan Kepadatan Pill Badge Tinggi**
   - Lokasi: `apps/web/app/pages/admin/layers/index.vue` (baris 1055-1315 dan 1330-1430).
   - Alasan: Setiap kartu status menampilkan empat komponen berbingkai paralel (dot status animasi + badge ms + pill count + badge/link endpoint) tanpa justifikasi tertulis untuk pemeringkatan hierarki antara kartu status server vs kartu filter KPI `4 kolom` di bawahnya.

7. **[LOW | R-31] Inkonsistensi Komponen Input Native vs UI Design System pada Modal Sync Martin**
   - Lokasi: `apps/web/app/pages/admin/layers/index.vue` (baris 2273-2278, 2306-2311).
   - Alasan: Seluruh halaman menggunakan komponen Nuxt UI (`UButton`, `UBadge`, `USwitch`, `UModal`, `USelect`), sementara checklist sumber Martin dan toggle `deactivate_missing` memakai `<input type="checkbox">` polos yang berbeda gaya di mode gelap.
