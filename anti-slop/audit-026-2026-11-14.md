## Temuan Audit UI (Mode 2)

1. **[LOW] Ukuran Touch Target Tombol Up/Down Inline pada Tabel Katalog Lama**
   - **Lokasi:** [index.vue](file:///c:/laragon/www/melarosa-laravel-nuxt/apps/web/app/pages/admin/layers/index.vue#L1631-L1651)
   - **Temuan:** Tombol `chevron-up` dan `chevron-down` inline pada kolom `Urutan` tabel Katalog lama masih menggunakan `p-1` sehingga ukuran target sentuhnya berada di bawah `44x44 px` pada layar sentuh, sedangkan pengaturan tumpukan di `ActiveLayersConfigPanel.vue` sudah memenuhi standar `min-h-[44px] min-w-[44px]`.
   - **Rekomendasi:** Pertimbangkan untuk mengarahkan penataan urutan antar-halaman langsung ke mode `Konfigurasi Layer Aktif & Urutan Peta` atau memperbesar tombol aksi baris pada breakpoint kecil.

2. **[LOW] Penggunaan Kelas `font-mono` Warisan pada Beberapa Sel Tabel Katalog**
   - **Lokasi:** [index.vue](file:///c:/laragon/www/melarosa-laravel-nuxt/apps/web/app/pages/admin/layers/index.vue#L1672-L1747)
   - **Temuan:** Baris tabel Katalog lama masih memiliki kelas `font-mono` pada tanggal sinkronisasi, hostname URL, badge protokol/styled, dan label pembacaan opacity, sementara `ActiveLayersConfigPanel.vue` dan bar counter sumber sudah beralih penuh ke `tabular-nums`.
   - **Rekomendasi:** Ganti kelas `font-mono` non-kode pada sel tabel Katalog dengan proporsional `tabular-nums` saat refactor tabel katalog berikutnya.

3. **[LOW] Dukungan Touch-Drag Pointer Langsung di Tablet/Ponsel pada Kartu Tumpukan**
   - **Lokasi:** [ActiveLayersConfigPanel.vue](file:///c:/laragon/www/melarosa-laravel-nuxt/apps/web/app/components/admin/layers/ActiveLayersConfigPanel.vue#L908-L926)
   - **Temuan:** Pengurutan via drag-and-drop saat ini memakai HTML5 Drag-and-Drop (optimal untuk pointer mouse desktop), sementara perangkat sentuh dan keyboard mengandalkan tombol `Naik`/`Turun` serta dropdown lompat urutan `#1..#N`.
   - **Rekomendasi:** Pertahankan kontrol tombol + dropdown untuk aksesibilitas penuh; touch-drag pointer opsional dapat ditambahkan di iterasi berikutnya jika admin sering menyusun puluhan layer lewat tablet.
